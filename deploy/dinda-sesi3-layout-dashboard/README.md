# Dashboard Customer Churn — Sesi 3

Dashboard Streamlit dengan sidebar filter, KPI cards, tabs, dan unduh CSV
(Buku Praktikum Interactive Dashboard Development with Streamlit & Dash, Sesi 3).

- `streamlit_app.py` — aplikasi (praktikum 3.3 + latihan mandiri Sesi 3)
- `data/customer_churn.csv` — data latihan sintetis, 3.000 pelanggan
- `requirements.txt` — library yang dipasang Streamlit Cloud

Jalankan lokal: `streamlit run streamlit_app.py`
